# Memoria.ia Server v0.1.0-alpha.1

Primeira versão instalável para validação em servidor próprio.

## Incluído

- instalação por Docker Compose;
- Memoria.ia v1.0.0rc2 fixada por commit;
- BDR v1.1.0 fixado por commit;
- runtime nativo da Memoria.ia;
- volume persistente;
- BDR Explorer demonstrativo e read-only;
- painel unificado;
- proxy interno com namespaces separados;
- health agregado;
- execução sem privilégios nos contêineres;
- configuração mock, OpenAI, Gemini e endpoint local compatível com OpenAI;
- scripts de instalação, atualização, status e parada;
- documentação de arquitetura e roadmap.

## Classificação

Alpha privada. Adequada para instalação controlada e testes do proprietário. Ainda não adequada para oferecer serviço comercial a clientes finais.

## Próximo marco

Registro interno de dispositivos e clientes, mantendo a memória pessoal sob controle do cliente final.
